# Yuvika Goel — Editorial Portfolio

A spacious, elegant portfolio made with HTML, CSS, and vanilla JavaScript. The design uses a warm paper palette, editorial typography, hand-drawn-inspired details, and a unique interactive **Idea Garden**.

## Features
- Responsive layout for desktop, tablet, and mobile
- Light/dark theme toggle with saved preference
- Mobile navigation and active-section indicator
- Project category filters
- Interactive Idea Garden with three selectable ideas
- Reading progress bar and subtle reveal animations
- Contact email copy helper
- Semantic HTML and reduced-motion support
- No frameworks or build tools required

## Run locally
1. Extract this folder and open it in VS Code.
2. Open `index.html` using Live Server, or open the file directly in a browser.
3. Personalise the placeholder content before publishing.

## Personalise before publishing
- Replace the sample GitHub and LinkedIn links with your real profiles.
- Replace `your.email@example.com` with a professional email address.
- Add your actual college/course details if you want them displayed.
- Link real project repositories and live demos.
- Keep project descriptions accurate. TrackBack AI is marked as an early-stage concept; keep it that way until you have a prototype and validation.
- Add a real resume PDF only if you have one ready.

## GitHub
Create a public repository named `yuvika-portfolio`, then push these files:

```bash
git init
git add .
git commit -m "Build editorial developer portfolio"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/yuvika-portfolio.git
git push -u origin main
```

Replace `YOUR-USERNAME` with your GitHub username. Never put passwords or access tokens into the source code.

## Vercel
1. Sign in at https://vercel.com/
2. Choose **Add New → Project** and import your GitHub repository.
3. Choose **Other** as the framework preset if asked.
4. This is a static website: no build command is needed and the output directory is the project root.
5. Deploy, then open the live URL Vercel provides.

When you push updates to the connected GitHub repository, Vercel can automatically redeploy.
